# Zamen • زامِن

> كل مقطع يجد لحظته — *Every clip finds its moment*

## المميزات

- اختيار عدة ملفات من الجهاز: **صوت وفيديو معاً** (MP3, WAV, M4A, OGG, FLAC, MP4, WEBM, MOV ...)
- يستخرج المسار الصوتي من ملفات الفيديو تلقائياً ويزامنه مع المقاطع الصوتية
- **مزامنة ذكية للكل**: بدون ملف مرجعي — أطول ملف يمثل الخط الزمني وتُحاذى بقية الملفات داخله أو داخل أي مقطع موضوع بالفعل، فتُدعم المقاطع المتصلة (المقسمة تلقائياً) والتداخلات الجزئية
- **قياس وتصحيح انجراف السرعة (Drift)** بين أجهزة التسجيل المختلفة عبر ملاءمة خطية على أجزاء قصيرة، مع عرض الانجراف بالمللي ثانية/دقيقة
- وضع المطابقة اليدوية: تعيين مرجع بنجمة ★ والبحث عن كل مقطع داخله
- الوضع التسلسلي: توقيت تراكمي مع قص صمت الأطراف بعتبة dB قابلة للتعديل
- إعادة ترتيب الملفات بالسحب والإفلات أو بالأزرار
- حقل إزاحة زمنية (Offset) لمزامنة البداية مع الفيديو
- صيغة توقيت بالفريمات `HH:MM:SS:FF` أو بالمللي ثانية `HH:MM:SS.mmm`
- تصدير النتائج بصيغ: `CSV` · `SRT` · `JSON` · `Audacity Labels` · `EDL (CMX3600)` · `TXT`
- واجهة ثنائية اللغة: العربية والإنجليزية
- بدون أي API — كل المعالجة تحدث محلياً داخل المتصفح ولا يُرفع أي ملف

## الأوضاع الثلاثة ومتى تستخدمها

| الوضع | الفائدة | متى تستخدمه |
|---|---|---|
| **مزامنة ذكية للكل** | محاذاة تلقائية بدون مرجع: أطول ملف أساس، وسلسلة تصل المقاطع المتابعة، وقياس انجراف السرعة، ودعم التداخل الجزئي | عدة تسجيلات (كاميرات/مسجلات) لنفس الحدث وأنت لا تعرف أيها الأدق |
| **مطابقة مع مرجع ★** | أنت تختار التسجيل المرجعي يدوياً، ويُحدد موقع بقية المقاطع داخله بنسبة ثقة | عندك تسجيل رئيسي معروف (صوت الفيديو) وتريد مواقع المقاطع داخله حصراً |
| **تسلسل تراكمي** | بناء خط زمني بترتيب القائمة مع إمكانية قص صمت الأطراف وفاصل منتظم | مقاطع متتابعة غير متداخلة: تعليق صوتي، حلقات بودكاست، أوصال تسجيل مقسم |

## صيغ التصدير وفائدتها

| الصيغة | الفائدة |
|---|---|
| **FCPXML** | DaVinci Resolve وFinal Cut — يفتح خطاً زمنياً كاملاً وكل مقطع على مسار مستقل (مسارات غير محدودة): مثالي لسيناريو صوت رئيسي واحد + عدة كاميرات زوايا؛ عند الاستيراد يطلب تحديد مجلد الملفات مرة واحدة فيربطها بالأسماء |
| **EDL (CMX3600)** | الاستيراد المباشر في Premiere Pro وDaVinci Resolve وFinal Cut — يبني أحداثاً في مواقعها الصحيحة، يوزع المقاطع المتداخلة على قنوات صوتية منفصلة (A/A2/A3/A4)، ويربط المصادر تلقائياً بأسماء الملفات، مع تعليقات الثقة والانجراف ونسبة السرعة المقترحة |
| **CSV** | تدقيق وفرز في Excel/Google Sheets — كل البيانات في أعمدة (ثوانٍ خام + تايم كود + ثقة + انجراف) |
| **JSON** | الأتمتة والتكامل البرمجي — بيانات منظمة لسكربتات المعالجة اللاحقة أو أدوات أخرى |
| **SRT** | مراجعة بصرية سريعة — أسماء المقاطع تظهر كترجمة فوق الفيديو في أي مشغل لتتأكد من المواقع |
| **Audacity Labels** | علامات جاهزة في Audacity (Import ← Labels) لتنظيف وتحرير المقاطع في مواضعها |
| **TXT** | قراءة سريعة أو مشاركة بسيطة بدون أي برنامج مونتاج |

## طريقة العمل

1. **فك الترميز**: تُقرأ الملفات عبر Web Audio API وتُحوَّل إلى قناة أحادية بمعدل 8kHz. لملفات الفيديو تُجرَّب القراءة المباشرة للمسار الصوتي، وإن تعذّرت يُشغَّل الملف داخلياً (حتى 8x) ويُلتقط صوته عبر Web Audio — كل ذلك محلياً في المتصفح
2. **كشف الصمت**: تحديد حدود المحتوى الصوتي بتحليل RMS مع عتبة dB قابلة للتعديل
3. **التسلسل**: حساب موضع كل مقطع تراكمياً حسب ترتيب القائمة مع الفاصل المحدد بين المقاطع
4. **المطابقة الذكية — تصويت الأجزاء**: يُقسَّم كل مقطع إلى أجزاء قصيرة (~2.5 ثانية) لا يتأثر انجراف الساعة داخلها، ويُبحث عن كل جزء داخل المصدر عبر تصالبية معايَرة محسوبة بـ FFT (Normalized Cross-Correlation)، ثم تُلاءَم خط مستقيم مع مواقع الأجزاء الناجحة فيُنتج موقعاً دقيقاً **ونسبة الانجراف معاً**
5. **السلسلة**: الملفات التي لا تتقاطع مع الخط الأساسي تُبحث داخل المقاطع الموضوعة سابقاً، فتتصل المقاطع المتتابعة تلقائياً، والتداخل الجزئي (تجاوز حدود المصدر) مدعوم
6. **الإزاحة**: إضافة الـ Offset على كل التوقيتات ثم توليد ملفات التصدير
